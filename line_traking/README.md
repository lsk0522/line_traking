# Advanced Line Tracker for TurtleBot (ROS Noetic)

이 저장소는 터틀봇(TurtleBot)과 PC를 무선으로 연결하여 구동되는 고성능 라인 트레이싱(차선 유지 주행) 노드들을 포함하고 있습니다.
카메라의 딜레이를 극복하기 위한 P-D 제어와, 주변 환경(하얀 바닥 등)의 노이즈를 무시하는 자율주행 대회(AutoRace) 수준의 차선 인식 알고리즘이 적용되어 있습니다.

## 📁 포함된 파일 (Nodes)

### 1. `line1.py` (최적화된 고급 알고리즘 - **추천**)
가장 빠르고 안정적인 주행을 위한 고급 라인 트레이싱 노드입니다.

- **핵심 기술 1 (바닥 노이즈 무시)**: 
  단순히 하얀색을 모두 찾는 것이 아니라, 카메라 화면을 '왼쪽 절반'과 '오른쪽 절반'으로 나눕니다.
  그 후, 각 절반 영역에서 **화면 중앙과 가장 가까운 선 1개씩만 선택**합니다. 이 방식을 통해 화면 양 끝에 보이는 거대한 하얀색 바닥(노이즈)을 완벽하게 무시하고 순수하게 2개의 차선만 추적합니다.
- **핵심 기술 2 (카메라 딜레이 보상 P-D 제어)**:
  Wi-Fi 통신으로 인한 카메라 영상 딜레이 때문에 발생하는 로봇의 오실레이션(좌우 흔들림)을 방지하기 위해 미분 제어(D-control)를 추가하여 조향을 부드럽게 만들었습니다.
- **핵심 기술 3 (실시간 파라미터 튜닝)**:
  로봇을 끄지 않고도 주행 중 키보드를 통해 속도, 조향 감도(Gain), 인식 영역(ROI)의 넓이와 높이를 실시간으로 조절할 수 있습니다.
- **구독(Subscribe)**: `/camera/image/compressed` (지연 방지를 위해 압축 이미지 사용)
- **발행(Publish)**: `/cmd_vel` (모터 제어 명령)

### 2. `line.py` (기본형 / 상태 머신형)
차선을 잃어버렸을 때 후진하거나 제자리 회전하는 등의 '상태 머신(State Machine)'이 적용된 기본형 노드입니다.
- **특징**: 단순히 화면 전체의 흰색 픽셀 중심점(Centroid)을 구하여 주행합니다. 복잡한 차선이 없는 단순한 환경에서 유용합니다.

## ⚙️ 기본 설정 (Default Parameters in `line1.py`)
현재 가장 안정적으로 테스트된 황금 비율(Golden Ratio) 셋팅값이 기본으로 적용되어 있습니다.
- `speed`: 0.05 (안정적인 코너링을 위한 속도)
- `turn_gain` (P 게인): 0.005
- `turn_gain_d` (D 게인): 0.015
- `ROI` (관심 영역): 상하 `0.8 ~ 0.9` (발밑 타겟), 좌우 `0.0 ~ 1.0` (전체 폭 스캔)

## 🚀 실행 방법 (How to Run)

### 1. 터틀봇 (로봇) 단말기 (SSH 접속)
터틀봇에서는 센서 구동과 카메라 촬영 노드만 실행합니다. (무거운 영상 처리는 하지 않습니다.)
```bash
# 터미널 1: 로봇 모터 및 기본 센서 켜기
roslaunch aicon_bringup aicon_robot.launch

# 터미널 2: 압축 이미지 전송용 카메라 켜기
roslaunch aicon_bringup aicon_camera.launch
```

### 2. PC 단말기
PC에서 터틀봇의 영상을 무선으로 넘겨받아 연산한 뒤 모터 제어 명령을 터틀봇으로 보냅니다.
```bash
# 터미널 1: 라인 트레이싱 노드 실행
rosrun color_pkg line1.py
```

## ⌨️ 실시간 키보드 조작 방법 (`line1.py`)
PC 터미널 창에서 프로그램이 켜져 있을 때 아래 키보드를 누르면 실시간으로 값이 변경됩니다.

- `[W] / [S]` : 직진 속도 증가 / 감소
- `[A] / [D]` : 회전 감도(Gain) 증가 / 감소 (로봇이 심하게 흔들리면 D를 눌러 감도를 낮추세요)
- `[I] / [K]` : 인식 영역 위/아래로 이동 (카메라가 멀리 보게 하려면 I, 발밑을 보게 하려면 K)
- `[J] / [L]` : 인식 영역 좁게/넓게 (차선 양옆의 바닥 노이즈가 심하면 J를 눌러 화면을 좁히세요)
- `[Q]` : 프로그램 종료
